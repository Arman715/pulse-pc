# Пульс ПК для iPhone

Приложение-компаньон для программы «Пульс ПК»: показывает на телефоне кадры в секунду,
загрузку процессора и видеокарты, видеопамять, оперативную память и пинг во время игры.
Данные идут напрямую с компьютера по домашней сети.

Проект — обычный SwiftPM-пакет в формате [xtool](https://github.com/xtool-org/xtool):
собирается и ставится на iPhone из Linux или Windows (через WSL), без Xcode.

## Что в папке

| Файл | Зачем |
| --- | --- |
| `Package.swift` | пакет с одним library-продуктом `PulsePhone` — это и есть приложение (так устроен шаблон `xtool new`) |
| `xtool.yml` | bundle ID `ru.pulsepc.phone`, путь к `Info.plist` и иконке |
| `Info.plist` | только дополнительные ключи; xtool сливает их со своими значениями по умолчанию |
| `Resources/AppIcon.png` | иконка 1024×1024 без прозрачности |
| `Sources/PulsePhone/` | код на SwiftUI |

## Подготовка (один раз)

Подробно — в документации xtool: *Installation (Linux/WSL)*.

1. Windows: установите WSL (Ubuntu) и USBIPD, чтобы пробросить iPhone в WSL по USB.
2. В WSL установите набор Swift для Linux (версию, которую требует текущий xtool) и `usbmuxd`
   (`sudo apt-get install usbmuxd`).
3. Скачайте `xtool.AppImage` из последнего релиза, переименуйте в `xtool`, положите в `PATH`.
4. Скачайте `Xcode.xip` с developer.apple.com (версию, указанную в документации xtool).
5. Выполните `xtool setup`: вход с Apple ID и путь к `Xcode.xip` — xtool соберёт из него iOS SDK.

## Сборка и установка

```bash
cd PulsePC/ios/PulsePhone
xtool dev
```

`xtool dev` собирает пакет, ждёт подключения iPhone по USB, регистрирует устройство на ваш
Apple ID, подписывает и устанавливает приложение. Первая сборка долгая — SwiftPM собирает модули SDK.

При первом запуске на телефоне:

- если появится «Доверять этому компьютеру?» — нажмите «Доверять» и снова запустите `xtool dev`;
- если iOS попросит — включите «Режим разработчика» (Настройки → Конфиденциальность и безопасность);
- «Ненадёжный разработчик»: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».

С бесплатным Apple ID подпись действует 7 дней — потом просто повторите `xtool dev`.

## Первое подключение

1. На компьютере: «Пульс ПК» → «Система» → «Панель на телефоне» → включить. Программа покажет QR-код и адрес
   вида `http://192.168.1.6:8765/gbnksz/`.
2. На iPhone: «Сканировать QR-код» (или введите адрес) → «Подключиться».
3. iOS спросит доступ к локальной сети — разрешите. Если проверка успела завершиться ошибкой
   до ответа на вопрос, нажмите «Подключиться» ещё раз.

Адрес сохраняется. Сменить его можно в настройках панели (шестерёнка).

## Как это работает

- Каждые 1,5 с приложение запрашивает `GET <адрес>d` (тайм-аут 3 с, эфемерная сессия, без кеша).
- 404 — неверный ключ; нет ответа — компьютер недоступен. При обрыве повторы идут с паузой до 5 с.
- В фоне опрос останавливается и возобновляется при возврате в приложение.
- Температура процессора не показывается.
