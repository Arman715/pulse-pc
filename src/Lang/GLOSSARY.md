# Pulse PC — English glossary

One program, one voice. US English, short and plain, sentence case for buttons and titles (only proper nouns capitalized).
Tone: calm, concrete, no hype, no exclamation marks, no "simply"/"just". Address the user as "you".
Never promise FPS gains: the program finds the cause, it does not "boost" or "speed up".

## Blueprint stamps (uppercase headers, spaced out by the program)
Keep them short and uppercase: ПРОТОКОЛ → LOG, ИГРОВЫЕ СЕССИИ → GAMING SESSIONS, ОТЧЁТ О ЗАПИСИ → RECORDING REPORT,
МОНТАЖ → INSTALLATION, ДЕМОНТАЖ → REMOVAL, ЛИСТ ОБЩИХ ДАННЫХ → GENERAL DATA SHEET, ХОД МОНТАЖА → PROGRESS,
ВЕРСИЯ → VERSION, ОБЪЁМ → SIZE, СИСТЕМА → SYSTEM, ЛИСТ 1/1 → SHEET 1/1.

## Units and numbers
GB, MB, KB, GHz, MHz, °C, W, ms, FPS, Hz, % (with a space before % in Russian, none in English: "93%").
Times: h, min, s. Dates come from the culture automatically (en-US) — use format strings, not hand-written month names.
Money: Russian ₽ amounts stay as numbers with the currency the user entered; say "per kWh", "rate".
Keep the non-breaking space (U+00A0) inside keys exactly as in the source; in translations use a normal space or U+00A0 between number and unit.
