# Бот «Пульс ПК» для Telegram

*Telegram bot for Pulse PC: download link, common questions, problem reports to the developer, and an automatic channel post for every new release. A single-file Cloudflare Worker with no dependencies; setup steps below are in Russian.*

Что умеет бот:

- **⬇ Скачать** — последняя версия, ссылка на установщик и SHA-256. Берёт их из `update.json` последнего выпуска на GitHub — из того же файла, по которому обновляется программа. Новую версию бот узнаёт сам.
- **❓ Частые вопросы** — 8 ответов кнопками (по инструкции программы).
- **✉ Сообщить об ошибке** — текст, снимки и файл `PulsePC-report-….zip` пересылаются разработчику. Чтобы ответить человеку, нажмите «Ответить» (reply) на пересланное сообщение — ответ уйдёт ему.
- **Автопост** — вышла новая версия на GitHub, и бот сам публикует пост в канале: что нового и кнопка «Скачать». Проверка раз в 30 минут.

Язык — русский для тех, у кого Telegram на русском, украинском, казахском и других языках СНГ; для остальных — английский.

Бот работает только в личных сообщениях. В группах он молчит, рассылок не делает. Токен хранится в настройках Cloudflare, в коде и в репозитории его нет.

## Установка (около 15 минут, один раз)

### 1. Создать бота в Telegram

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя: `Пульс ПК`. Адрес: `pulsepc_official_bot` (23.11.2026 был свободен; запасной — `pulsepc_help_bot`).
3. BotFather пришлёт **токен** вида `123456789:AA…`. **Никому его не отправляйте**, даже в этот чат — он понадобится только на шаге 4.
4. Там же у @BotFather:
   - `/setuserpic` → выберите бота → пришлите `promo\telegram\avatar.png`;
   - `/setjoingroups` → выберите бота → **Disable** (бот не нужен в группах).

### 2. Завести Cloudflare (бесплатно)

Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up) — почта и пароль ваши. Карта не нужна: бесплатного тарифа хватает с большим запасом (100 000 запросов в день).

### 3. Создать Worker и вставить код

1. **Workers & Pages** → **Create** → **Create Worker** (шаблон «Hello World»). Имя: `pulsepc-bot` → **Deploy**.
2. **Edit code** → удалите всё в `worker.js` и вставьте содержимое файла [`worker.js`](worker.js) из этой папки → **Deploy**.

### 4. Настройки Worker'а

Откройте Worker `pulsepc-bot` → **Settings**.

1. **Хранилище (KV).** Сначала в меню слева **Storage & Databases** → **Workers KV** → **Create instance** → имя `pulsepc-bot`.
   Затем откройте Worker → вкладка **Bindings** → **Add binding** → **KV namespace**. Variable name: **`BOT_KV`**, namespace — `pulsepc-bot` → **Add binding**.
2. **Токен.** **Variables and Secrets** → **Add** → тип **Secret**, имя **`BOT_TOKEN`**, значение — токен от BotFather → **Deploy**.
3. **Расписание.** **Settings** → **Trigger Events** (или **Triggers**) → **Add** → **Cron Triggers** → `*/30 * * * *`.
   Cloudflare включает новое расписание в течение 15 минут.

### 5. Подключить бота к Telegram

Откройте в браузере адрес Worker'а с `/setup` на конце, например `https://pulsepc-bot.<ваше-имя>.workers.dev/setup`.
Адрес Worker'а показан на его странице (Domains & Routes / Preview).

Должно быть:

```
setWebhook: ok
ru: commands ok, description ok, short ok
en: commands ok, description ok, short ok
ADMIN_ID: not set — …
```

### 6. Указать, кому пересылать сообщения

1. Напишите своему боту `/id` — он ответит числом.
2. Worker → **Settings** → **Variables and Secrets** → **Add** → тип **Text**, имя **`ADMIN_ID`**, значение — это число → **Deploy**.

### 7. Сделать бота администратором канала

Канал → «Управление каналом» → «Администраторы» → «Добавить администратора» → найдите бота.
Оставьте только **«Публикация сообщений»**, остальные права выключите.

При первой проверке по расписанию бот запоминает текущую версию (1.5.0) и **не** публикует о ней пост: он уже есть в канале. Следующая версия появится в канале сама.
Поэтому настройте бота до выхода следующей версии: выпуск, который вышел раньше первой проверки, бот только запомнит.

### 8. Проверить

- `/start` → «Скачать» — версия и ссылка;
- «Частые вопросы» → любой вопрос;
- «Сообщить об ошибке» → напишите что-нибудь с другого аккаунта (или со своего) — сообщение придёт вам; ответьте на него reply — ответ уйдёт обратно.

## Как обновить код бота

Worker → **Edit code** → вставьте новый `worker.js` → **Deploy**. Настройки, хранилище и расписание сохранятся.
Если публикуете через командную строку (`npx wrangler deploy`), в `wrangler.toml` уже стоит `keep_vars = true` — иначе Wrangler стёр бы `ADMIN_ID`, заданный на сайте. `/setup` открывать заново не нужно — только если поменялись команды.

## Проверка без Telegram

```powershell
node test.mjs
```

Запросы к Telegram подменяются, данные о выпуске берутся с настоящего GitHub. Проверяются меню, ответы, пересылка и ответы разработчика, лимит 20 сообщений в сутки, автопост и разметка всех текстов.

## Если что-то не так

- **Бот молчит.** Откройте `/setup` ещё раз — должно быть `setWebhook: ok` (сообщения, которые ждут в очереди, при этом не теряются). Если там ошибка `Unauthorized` — неверный токен.
- **Автопост не вышел.** Бот пришлёт вам причину (обычно он не администратор канала) и попробует снова через 30 минут.
- **Логи.** Worker → **Logs** (Observability): там видны ошибки Telegram.
- **Токен утёк.** @BotFather → `/revoke` → новый токен → замените секрет `BOT_TOKEN` → откройте `/setup`.
